# CryptoMetrics

Веб-API на ASP.NET Core для технического анализа криптовалют. Сервис получает данные из публичного API CoinGecko, рассчитывает индикаторы SMA, EMA, RSI и возвращает краткий вывод по выбранной монете. Документация API доступна в Swagger UI по адресу `/swagger`.

Репозиторий: <https://github.com/VladimirM05/crypto-metrics>

## Назначение и аудитория

Сервис избавляет от ручной обработки рыночных данных: достаточно одного HTTP-запроса, чтобы получить историю цен и готовые значения индикаторов.

Для кого:
- трейдеры и аналитики — быстрая оценка состояния монеты;
- разработчики — подключение API к своим приложениям и ботам;
- студенты — пример многослойного веб-API с документацией Swagger.

## Функции

- Список криптовалют: топ-20 по рыночной капитализации с текущей ценой в USD.
- Создание анализа по тикеру и периоду (2–365 дней).
- Расчёт индикаторов: SMA (простая скользящая средняя), EMA (экспоненциальная скользящая средняя), RSI (индекс относительной силы). Если индикаторы не указаны, считаются SMA(7), EMA(7), RSI(14).
- Текстовый вывод: изменение цены за период, зона RSI (перекупленность, перепроданность, нейтральная), положение цены относительно SMA/EMA.
- История анализов: просмотр списка и поиск по `id`.
- Проверка входных данных и понятные сообщения об ошибках.
- Кэширование ответов CoinGecko (список монет — 5 минут, история цен — 10 минут).

## API

| Метод | Маршрут | Назначение | Ответы |
|---|---|---|---|
| GET | `/api/Cryptocurrencies` | Список криптовалют | 200, 503 |
| GET | `/api/Analysis` | Все выполненные анализы | 200 |
| GET | `/api/Analysis/{id}` | Анализ по идентификатору | 200, 404 |
| POST | `/api/Analysis` | Создать анализ | 201, 400, 404, 503 |

Тело запроса `POST /api/Analysis`:

| Поле | Тип | Ограничения | По умолчанию |
|---|---|---|---|
| `symbol` | string | обязательное, 1–10 символов (например, `BTC`) | — |
| `days` | int | от 2 до 365 | 30 |
| `indicators` | array | необязательное | SMA(7), EMA(7), RSI(14) |
| `indicators[].name` | string | `SMA`, `EMA` или `RSI` | — |
| `indicators[].period` | int | от 2 до 200 | 14 |

Пример запроса:

```bash
curl -X POST http://localhost:5071/api/Analysis \
  -H "Content-Type: application/json" \
  -d '{"symbol": "BTC", "days": 30, "indicators": [{"name": "SMA", "period": 7}]}'
```

Коды ошибок: `400` — неверные данные (например, мало точек для расчёта индикатора), `404` — тикер или анализ не найден, `503` — CoinGecko недоступен или превышен лимит запросов.

## Архитектура и технологии

- .NET 11, ASP.NET Core Web API (контроллеры).
- Swashbuckle.AspNetCore — Swagger / OpenAPI и Swagger UI.
- CoinGecko API v3 — источник данных, обращение через типизированный `HttpClient`.
- `IMemoryCache` — кэш в памяти.
- Анализы хранятся в памяти приложения. База данных не используется, при перезапуске данные очищаются.
- Внедрение зависимостей: `IExternalApiService`, `IIndicatorService`, `IMarketAnalysisService`.
- Хостинг: Amvera Cloud (`amvera.yaml`).

Структура проекта:

```
Controllers/   контроллеры API (Cryptocurrencies, Analysis)
Services/      работа с CoinGecko, расчёт индикаторов, логика анализа
Models/        модели запросов и ответов
Program.cs     настройка сервисов, Swagger и маршрутов
amvera.yaml    конфигурация развёртывания
```

## Запуск

Требуется [.NET SDK 11](https://dotnet.microsoft.com/download) и Git.

```bash
git clone https://github.com/VladimirM05/crypto-metrics.git
cd crypto-metrics
dotnet run
```

Swagger UI: <http://localhost:5071/swagger>

Примечание. В `Program.cs` есть строка `app.Urls.Add("http://0.0.0.0:80")`, она нужна для Amvera. Если порт 80 занят или недоступен, закомментируйте её при локальном запуске.

Ключ CoinGecko (необязательно). Без ключа сервис работает, но у публичного API есть лимит запросов. Чтобы добавить демо-ключ, укажите в `appsettings.json`:

```json
"CoinGecko": { "ApiKey": "ваш_ключ" }
```

или задайте переменную окружения `CoinGecko__ApiKey`. Не публикуйте ключ в репозитории.

Развёртывание в Amvera:

```bash
git remote add amvera <адрес репозитория проекта в Amvera>
git push amvera main
```

Сборка и запуск выполняются автоматически по `amvera.yaml`. Swagger UI будет доступен по адресу `https://<домен проекта>/swagger`.

## Ограничения

- Анализы хранятся только в памяти.
- Доступны только монеты из топ-20 по капитализации.
- Бесплатный API CoinGecko ограничивает частоту запросов.
